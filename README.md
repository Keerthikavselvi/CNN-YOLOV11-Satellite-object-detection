CNN-YOLOv11 Satellite Image Object Detection

A deep learning project focused on detecting objects in satellite images using Python, PyTorch, YOLOv11, and CNN architectures.

Technologies Used:
Python
PyTorch
YOLOv11
ResNet50
VGG19
OpenCV

About the Project:
Developed an object detection pipeline for satellite imagery, covering image preprocessing, model training, and evaluation.
Experimented with CNN architectures, including ResNet50 and VGG19, alongside YOLOv11 for object detection.
Tuned model parameters and monitored overfitting to improve detection performance.
Optimized batch processing to reduce inference processing time.

Results:
Achieved 92% detection accuracy.
Reduced inference processing time by 25% through batch processing and model optimization

Future Improvements:
Improve detection performance on diverse satellite images.
Experiment with different model configurations.
Further optimize inference speed.
